# HYZK-GEO

华阳智瞰 GEO 2.0 进阶版陪跑业务宣传网站。浅绿色主题，使用新版公司 Logo。

## 当前版本：精简动效版

页面由 11 个区域精简为 4 个：首屏卖点、2.0 升级、AI 五步工作流、联系我们。保留内容架构摘要、邮箱、余杭区城西分部地址和微信二维码。

动效包括移动网格、渐变背景与标题、按钮扫光、流程节点轮流点亮、卡片悬浮、分组入场及阅读进度条。遵循系统减少动态效果设置，并在页面隐藏时暂停动画。

## 查看与发布

双击 `index.html` 即可本地查看，无外部脚本或字体依赖。

- 本地预览：`npm run dev`
- 静态检查：`npm run check`
- 构建成品：`npm run build`

无需安装第三方依赖。Node.js 20+。发布文件位于 `dist/`。

上传步骤见 `docs/GitHub部署说明.md`。本轮仅修改本地文件，尚未发布。

## 本轮验证

验证 1440px 桌面及 320、390px 手机竖屏，无横向溢出；菜单、咨询区二维码正常，未记录浏览器脚本错误。

这是业务介绍网页，流程动画仅表示服务环节，不代表后台正在运行任务。2.0 自动化方向依据用户确认；具体平台、交付数量及周期需按服务方案核对。
