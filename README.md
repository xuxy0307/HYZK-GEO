# 华阳智瞰 · GEO

## 当前版本：品牌双站统一版

AIGC 深墨绿、GEO 浅绿暖白。两站共用布局、字号、导航、服务卡片、流程、应用场景、FAQ 与咨询交互规范，独立部署。`styles.css` 与 `script.js` 保持相同；修改公共体验时需同步两站。

页面只展示实际服务方向，不把未经补充验证的数字成果当作通用承诺。应用场景不是客户案例。邮箱、地址与二维码沿用项目原有资料。

## 本地查看

直接打开 `index.html`。也可在两个项目的共同父目录运行本地静态服务器，同时访问 `/HYZK-AIGC/` 和 `/HYZK-GEO/`，本地业务切换支持兄弟目录。发布后业务入口使用 GitHub Pages 地址。

## 检查与构建

- `npm run check`：脚本语法、页面锚点和本地资源检查。
- `npm run build`：输出静态成品到 `dist/`。
- 无外部脚本、字体或运行时依赖。
